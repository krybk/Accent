# Accent

Android-пульт к серверной нейросетевой инфраструктуре. Приложение хранит профили
серверов, разворачивает на выбранный сервер контейнерный стек и общается с ним
из чата: текст, изображения, файлы, видео, голос.

Этот репозиторий одновременно — **шаблон конвейера приложений**. Будущие
приложения форкают его и выкидывают прикладную часть, оставляя обвязку.

## Что переносится в новое приложение, а что нет

| Каталог | Роль |
| --- | --- |
| `.github/workflows/` | конвейер, переносится целиком |
| `scripts/` | конвейер, переносится целиком |
| `.claude/` | конвейер, переносится (записи чистятся) |
| `app/` | прикладное, переписывается |
| `gateway/` | прикладное, переписывается |

## Технологии

- **Приложение**: Tauri v2, ядро на Rust, интерфейс на React + TypeScript.
  Android собирается только в CI: на сервере нет ни Java, ни Android SDK.
- **Шлюз**: Rust (axum) в Docker, рядом LiteLLM, Postgres и Caddy.
- **SSH**: `russh` в ядре приложения. Пароль рута вводится один раз при
  бутстрапе и на устройстве не сохраняется.

## Команды

- `npm test` — тесты фронтенда
- `npm run typecheck` — проверка типов
- `./scripts/check-secrets.sh` — секреты в индексе (входит в CI)
- `node scripts/cache-canary.js [модель]` — работает ли кеширование промпта

## Репозиторий публичный

В историю не попадает ни один секрет. Токен шлюза, TLS-сертификаты, ключи
провайдеров, keystore для подписи APK генерируются на целевой машине или лежат в
GitHub Secrets. В репозитории только `*.example`.

`scripts/check-secrets.sh` — последняя сетка, а не первая линия: он ловит
известные форматы ключей и запрещённые имена файлов. Появилось новое место, где
может завестись секрет — правь одновременно `.gitignore` и этот скрипт.

## Модели и деньги

Доступ к моделям идёт через OpenRouter (`ANTHROPIC_BASE_URL`). Ниже — не общие
слова, а замеренные на этом проекте факты. Они меняют выбор тарифа, поэтому
живут здесь, а не в чьей-то памяти.

**Точные ID моделей, не алиасы.** `~anthropic/claude-opus-latest` однажды молча
переедет на модель дороже. Смена версии должна быть видимым коммитом.
Существующие ID: `anthropic/claude-opus-5`, `anthropic/claude-sonnet-5`,
`anthropic/claude-haiku-4.5`. Модели `claude-haiku-5` **не существует** — она
стояла в окружении и роняла каждый вызов дешёвого тарифа с `400 not a valid
model ID`, отправляя работу на тарифы дороже.

**Закрепляй провайдера.** Модели Anthropic на OpenRouter раздаёт не один
провайдер: у `haiku-4.5` их восемь, у `sonnet-5` — девять (Anthropic, Google,
Azure, Bedrock). Без закрепления соседние запросы уходят к разным провайдерам и
кеш префикса не переживает переезд. В каждом запросе:

```json
"provider": { "order": ["Anthropic"], "allow_fallbacks": false }
```

**Haiku дешевле не всегда.** Минимальный кешируемый префикс замерен
эмпирически: Sonnet 5 кешируется от ~1024 токенов, Haiku 4.5 — только от ~4096.
Ниже порога кеш не создаётся молча. На коротком префиксе вход Haiku по $1.00/1M
выходит дороже кешированного входа Sonnet по $0.20/1M. Вывод: Haiku — для
механической работы с длинным стабильным префиксом, а не для коротких запросов.

**Основная статья расхода — не длина ответа, а повторная пересылка истории** на
каждом вызове инструмента. У Sonnet запись в кеш стоит $0.0123 против $0.0010 за
чтение — разница в 12 раз на одном и том же префиксе. Отсюда: рабочий кеш важнее
выбора тарифа, и `cache-canary.js` гоняется после любой правки промптов.

**Тарифы по задачам.** Sonnet — по умолчанию на весь автоматический цикл. Opus —
только когда `@claude` пишет человек. Всё, что пишут сами workflow, содержит
маркер `<!-- automated-request -->`, по которому `claude.yml` оставляет обращение
на Sonnet: иначе цикл эскалировал бы сам себя до Opus, ведь разбудить его можно
только упоминанием `@claude`.

## Память между сессиями

Два файла, у них разные роли — не смешивать:

- `.claude/journal.md` — **историческая справка**: что замерено, что решено и
  почему, включая опровергнутые гипотезы. Читай его в начале работы над
  экономией, моделями или инфраструктурой: там лежат цифры, которых нет в коде,
  и причины решений, которые иначе выглядят произвольными. Выяснил что-то новое
  и неочевидное — добавь запись тем же PR.
- `.claude/known-failures.md` — **разобранные причины падений** CI и сборки.
  Читай его **до** исследования репозитория, если чинишь упавший прогон.
  Записи «не возвращать» означают, что решение уже пробовали и оно не работает.

Правило для обоих: сюда идёт то, что не выводится из кода. Структура проекта,
история git и содержимое конфигов дублированию не подлежат.
