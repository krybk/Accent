# Accent

Android-пульт к серверной нейросетевой инфраструктуре.

Вы добавляете сервер в приложение — адрес, порт, учётные данные рута, — и
приложение само разворачивает туда контейнерный стек: шлюз, маршрутизатор
моделей, базу. Дальше вы общаетесь с этим сервером из чата: текст, изображения,
файлы, видео, голосовые сообщения. Серверов может быть несколько, и их можно
попросить связать между собой ключами или туннелями.

По духу это AmneziaVPN, но вместо туннеля разворачивается нейросетевая
инфраструктура.

## Как устроен доступ

Рут-пароль вводится **один раз** и на устройстве не сохраняется. При добавлении
сервера приложение:

1. подключается по SSH с этим паролем;
2. генерирует ключ и кладёт приватную часть в хранилище ключей телефона;
3. дописывает публичную часть в `authorized_keys`;
4. ставит Docker, если его нет, поднимает стек и выпускает токен;
5. забирает токен и сертификат, стирает пароль из памяти.

Дальше приложение говорит только со шлюзом — по TLS, с токеном и пиннингом
сертификата. Украденный телефон не даёт рута, а токен отзывается с сервера.

## Состояние

Ранняя разработка. Готово: гигиена репозитория и проверка кеширования моделей.
В работе: шлюз, профили серверов, текстовый чат.

## Модели

Через шлюз доступны Haiku, Sonnet и Opus, а также сторонние модели — напрямую
или через OpenRouter, с переключением из интерфейса. Учёт расхода ведётся по
каждому вызову: это оказалось важнее выбора тарифа, потому что основные деньги
уходят не на длину ответа, а на повторную пересылку истории. Замеры и выводы —
в [`.claude/journal.md`](.claude/journal.md).

Проверить, что кеширование промпта действительно работает:

```
OPENROUTER_API_KEY=... node scripts/cache-canary.js anthropic/claude-sonnet-5
```

## Шаблон конвейера

Репозиторий одновременно служит шаблоном для следующих приложений: обвязка
(`.github/`, `scripts/`, `.claude/`) переносится целиком, прикладная часть
(`app/`, `gateway/`) переписывается. Разметка — в
[`CLAUDE.md`](CLAUDE.md).
